# Emotion Detector

This project is an AI-based web application that detects emotions from text using the IBM Watson NLP library.

## Project Description

The Emotion Detector analyzes a given text and identifies the following emotions:

- Anger
- Disgust
- Fear
- Joy
- Sadness

It also identifies the dominant emotion.
